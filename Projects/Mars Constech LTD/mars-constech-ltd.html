Project Preview
01 / Overview

The Challenge

Pacific Academy approached with an outdated institutional website that suffered from an aging design, critical WordPress security vulnerabilities, and a content management experience the editorial team had grown to resent. The objective was a complete digital transformation — not a surface-level facelift, but a ground-up rethink of every touchpoint.

The institution required a platform that could simultaneously serve as a professional marketing asset, a secure content hub, and a practical daily tool for non-technical staff. Every decision — from architecture to colour — had to serve these three distinct audiences.

Screenshot — Before / After Comparison

Side-by-side redesign comparison — legacy design vs. the modern rebuilt interface.

02 / Solution

The Approach

I began with a comprehensive UX audit and security penetration review, mapping every vulnerability before a single line of new code was written. The rebuild proceeded in two parallel tracks: a new design system built in Figma, and a hardened WordPress architecture on the engineering side.

01
Discovery & Audit

Full security scan, content inventory, and stakeholder interviews to define the new information architecture and design direction.

02
Design System

High-fidelity Figma prototype with component library — covering typography, colour, spacing, and all UI states — approved before development began.

03
Custom Theme Engineering

Bespoke WordPress theme built from scratch. No page builder. Custom Gutenberg blocks for the editorial team's specific content patterns.

04
Security Hardening

Patched all identified vulnerabilities, implemented WAF rules, hardened wp-admin access, and deployed security headers for an A+ rating.

05
Optimisation & Handoff

Performance tuning to sub-2s LCP, staff training documentation, and a 30-day post-launch support period for zero-friction adoption.

Screenshot — Responsive Across Devices

Mobile-first responsive implementation — pixel-perfect from 320px to 2560px.

03 / Results

The Outcome

The relaunched platform delivered measurable impact from day one. Page load times were cut in half, all critical security vulnerabilities were resolved, and the editorial team reported a significantly improved content workflow. The Executive Director described it as exactly what they needed — both high-quality design and a secure backend.
